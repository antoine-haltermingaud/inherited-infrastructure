# Rejected ideas — 09-GithubOidc

- Rotate the static keys on a schedule instead — still a long-lived credential class; rotation cadence is a treadmill, OIDC removes the class.
- Wildcard trust policy (`repo:org/*`) — any repo in the org could deploy pricefeed; pin to repo+branch.
- Delete the old keys the same day — a broken trust policy discovered Monday with no fallback is a deploy freeze; deactivate, then delete.
