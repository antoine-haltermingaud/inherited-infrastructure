# Requirements — 09-GithubOidc

**Planned for Delta week one (Friday). Deliberately NOT implemented in the take-home** — requires the AWS account.

## Acceptance criteria

- Deploy workflow authenticates via `aws-actions/configure-aws-credentials` with `role-to-assume`; no `aws-access-key-id` anywhere.
- Trust policy restricted to this repository AND `refs/heads/main` (sub claim) — a fork or feature branch cannot assume it.
- One green deploy on OIDC, THEN: static keys deleted from GitHub secrets and the IAM user deactivated (deactivate first, delete after a quiet week).
- The IAM user's other access (console? other pipelines?) checked before deactivation.

## Constraints

- Keep the old keys working until the first OIDC deploy succeeds — no self-inflicted deploy freeze.
