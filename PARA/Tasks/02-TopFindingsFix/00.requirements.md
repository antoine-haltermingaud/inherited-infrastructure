# Requirements — 02-TopFindingsFix

Deliverable: one git commit on `main` fixing **only** the top 2–3 findings.

## Acceptance criteria

- Scope held to 2–3 findings. A larger diff is a failure, not extra credit.
- `npx cdk synth` succeeds with no AWS credentials; `npx tsc` clean.
- Nothing is deployed; no AWS account used.
- Commit message written for a real team, covering: what changed and why, what is
  deliberately out of scope, and the rollout risk on a *running production* system
  plus the mitigation.
- Fixes that cannot be applied to a live system without downtime are either sequenced
  safely or explicitly deferred in `REVIEW.md` instead of being merged blind.

## Constraints

- Budget ~60 minutes of the 4-hour box.
