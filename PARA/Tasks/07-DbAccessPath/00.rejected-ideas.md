# Rejected ideas — 07-DbAccessPath

- SG-to-SG in a single deploy from ServiceStack — DataStack deploys first under `--all`, revoking the old rule before the new one exists: app→DB outage window (disagreement log, task 02).
- Bastion EC2 host — an always-on instance to patch and pay for, for a handful of engineers; EICE does it instance-less.
- Client VPN — cost and operational overhead out of proportion to "a few engineers need occasional Workbench".
- Keep VPC-CIDR "since it's private anyway" — lateral movement from any compromised VPC workload reaches 3306; SG-to-SG is the same effort with a real boundary.
